# 🕵️ Найди шпиона

Онлайн-игра для компании друзей прямо в браузере. Все игроки видят одну картинку (эмодзи), а шпион — похожую. Описывайте свою картинку по очереди, не называя её прямо, и вычисляйте чужака голосованием.

## Возможности

- Комнаты по 4-значному коду, от 4 до 8 игроков
- Раунды: обсуждение с таймером → голосование → результат
- Настройки: 1–2 шпиона, время раунда, тема картинок, режим «слепой шпион»
- Счёт между партиями, зрители
- Голосование за исключение игрока из комнаты (кнопка 🗳 вверху): нужно большинство голосов «за», хоста исключить нельзя
- Свои пары слов/эмодзи (любой игрок добавляет в лобби, тема «Свои»)
- Если шпиона вычислили, он один раз может угадать картинку мирных и всё равно победить
- Ничья в голосовании → переголосование между лидерами
- Очередь описаний: подсветка говорящего и кнопка «Я закончил»
- Ссылка-приглашение `?room=КОД` и кнопка «Скопировать ссылку»
- Картинка скрыта, пока её не удерживают
- Текстовые описания можно выключить (общение в Дискорде)
- Без сервера: игроки соединяются напрямую через [PeerJS](https://peerjs.com/) (WebRTC), роль сервера выполняет хост комнаты

## Запуск на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (файл `index.html` должен лежать в корне).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Локально: `python3 -m http.server` в этой папке и откройте `http://localhost:8000`.

## Важно знать

- Если хост пропал или вышел, роль переходит к следующему игроку (кто раньше вошёл). Текущая партия сбрасывается в лобби, счёт сохраняется. Бывший хост может вернуться обычным игроком.
- Для связи используются публичные серверы PeerJS, Google STUN и бесплатный TURN `openrelay.metered.ca`. Для постоянной игры лучше подставить свой TURN в константу `ICE` в `js/app.js`.
- Шрифты и PeerJS подгружаются с CDN, нужен интернет.
- Лицензию (например, MIT) добавьте сами на своё усмотрение.

## Ошибка «Нет связи с сервером (network)»

Тип `network` в PeerJS означает: браузер не смог подключиться к **сигнальному серверу** (по умолчанию бесплатное облако `0.peerjs.com`). GitHub Pages тут ни при чём — он отдаёт только статику. Облако PeerJS работает без гарантий, иногда падает и в ряде стран/у ряда провайдеров блокируется. Игра теперь делает несколько повторных попыток, но надёжное решение — свой сервер сигналов (бесплатно):

1. Загрузите папку `server/` в отдельный репозиторий (или весь проект, Root Directory = `server`).
2. На [render.com](https://render.com): New → Web Service → этот репозиторий. Build: `npm install`, Start: `npm start`. Тариф Free.
3. Получите адрес вида `my-spy-peer.onrender.com` и впишите в `js/config.js`:
   ```js
   window.SPY_CONFIG={ peers:[{host:'my-spy-peer.onrender.com',port:443,path:'/',secure:true},{}] };
   ```
4. Закоммитьте `config.js` в GitHub. (На бесплатном Render сервер «засыпает» — первое подключение может занять ~30–60 с.)

## Свои серверы

В `js/config.js` можно указать свой PeerJS-сервер (`peers`) и свой TURN (`turn`) — без правки `app.js`.
